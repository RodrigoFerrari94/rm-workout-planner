# RM Workout Planner — Architecture

## Technology Stack

Frontend:
- React

Backend:
- Firebase

Build Tool:
- Vite


## Project Structure

The application will follow a modular structure.

src/

- components
- pages
- hooks
- services
- utils
- data


## Components

Reusable UI components such as:

- buttons
- inputs
- timers
- exercise cards


## Pages

Main application views:

- Home
- 1RM Calculator
- Workout Builder
- Workout Session
- Workout History
- User Profile


## Services

Services handle communication with external systems.

Examples:

- Firebase authentication
- database operations


## Hooks

Custom React hooks for reusable logic.

Examples:

- workout logic
- timer logic
- calculator logic


## Utils

Utility functions used across the application.

Examples:

- 1RM calculation formulas
- percentage calculations


## Data

Static data used by the application.

Examples:

- exercise list
- muscle groups
- training goal definitions
